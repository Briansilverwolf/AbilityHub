# STORY-001 — Upload CV and create searchable profile

**As a** job seeker,
**I want to** upload my CV and have the system extract relevant information to create a searchable profile,
**so that** I can be discovered by businesses and opportunity seekers without manually applying to each posting.

## Task list
- Accept CV upload in common formats (PDF, DOC, DOCX, TXT)
- Extract structured information from CV (skills, experience, education, qualifications)
- Store extracted data in a searchable database format
- Allow user to review and correct auto-extracted information
- Provide option for manual information entry alongside/ instead of auto-extraction
- Create a user profile from the captured/entered information
- Enable profile updates, deletion, and deactivation
- Ensure deactivated profiles are not visible to businesses/opportunity seekers
- Restrict profile viewing to the owning user only

## Notes
- Addresses pain point: Job seekers currently must search online for job postings and manually send CVs to each opportunity (current-state.md)
- Supports business goal: Prevent sending information to untrusted parties through privacy controls (business-goals.md)
- Enables desired future state: Job seekers can upload CVs and become visible in relevant searches without manual application (Phase 4)
- Relates to stakeholder: Job Seekers (stakeholders.md)

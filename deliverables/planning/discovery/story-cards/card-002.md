# STORY-002 — Search for qualifications and get candidate suggestions

**As a** business or opportunity seeker,
**I want to** search for specific qualifications and receive targeted candidate suggestions,
**so that** I can efficiently find qualified candidates without advertising or screening unqualified applicants.

## Task list
- Provide search interface for qualifications, skills, experience, education criteria
- Query the candidate profile database based on search criteria
- Return ranked suggestions of matching candidates
- Allow filtering and refinement of search results
- Display candidate profile summaries (with privacy-protected sensitive information)
- Enable initiating contact or viewing full profile (subject to privacy settings)
- Save and reuse search queries
- Set up alerts for new matching candidates

## Notes
- Addresses pain point: Businesses must advertise job openings and screen many unqualified applications (current-state.md)
- Supports business goal: Make it easy for companies to get qualified workers easily (business-goals.md)
- Enables desired future state: Businesses can search for qualifications and get suggestions (Phase 4)
- Relates to stakeholder: Businesses/Hiring Entities and Opportunity Seekers (stakeholders.md)

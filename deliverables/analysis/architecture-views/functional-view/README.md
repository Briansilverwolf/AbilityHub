# Functional View

This directory contains the use‑case specifications for the system.

## Files

- `uc-001-upload-cv-create-searchable-profile.md` – Use case UC‑001: Upload CV and create a searchable profile.
- `uc-002-search-qualifications-get-candidate-suggestions.md` – Use case UC‑002: Search for qualifications and get candidate suggestions.
- `uc-003-implement-job-categorization-cv-upload-limits.md` – Use case UC‑003: Implement job categorization and CV upload limits.
- `uc-004-view-profile-insights-analytics.md` – Use case UC‑004: View profile insights and analytics.
- `uc-005-receive-notifications-profile-views-interactions.md` – Use case UC‑005: Receive notifications for profile views and interactions.
- `use-case-diagram.md` – UML use‑case diagram showing all five use cases and their relationships.

Each use‑case file includes:
- Brief description
- Main flow (step‑by‑step)
- Alternate/error flows
- Pre‑ and post‑conditions (where applicable)

These documents capture the functional requirements from the user’s perspective.

## FEAT-007 — Profile Analytics and Insights Feature

id: FEAT-007
type: feature
realizes: [CAP-REQ-007]
details: |
  The Profile Analytics and Insights feature tracks profile view events including viewer type, timestamp, and search context. It provides comprehensive dashboards showing total profile views over time, breakdowns by viewer type and job category, search terms that led to profile views, and recent viewers with privacy protections. Users can filter insights by date range and export summary views for further analysis.

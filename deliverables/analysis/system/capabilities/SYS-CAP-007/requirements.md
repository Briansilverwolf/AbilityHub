## CAP-REQ-007 — Profile Analytics and Insights Requirement

id: CAP-REQ-007
type: capability-requirement
supports: [SYS-CAP-007]
derived-from: [BUS-REQ-007]
realized-by: [UC-003]

The system shall track and store profile view events, provide analytics dashboards with view metrics and breakdowns, show search terms that led to profile views, display recent viewers with privacy protections, allow filtering by date range, and provide export capabilities for insights.

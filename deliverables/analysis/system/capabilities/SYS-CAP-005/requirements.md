## CAP-REQ-005 — Job Categorization Requirement

id: CAP-REQ-005
type: capability-requirement
supports: [SYS-CAP-005]
derived-from: [BUS-REQ-005]
realized-by: [UC-002]

The system shall implement a job categorization/classification system (e.g., by industry, role type, skill domain) and allow users to browse/search opportunities by job category.

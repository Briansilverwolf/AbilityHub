# Features

## FEAT-001: Profile Management Feature
Groups capability requirements related to managing candidate profiles, including CV ingestion, profile data management, and upload constraint enforcement.
- **Groups**: CAP-REQ-001, CAP-REQ-002, CAP-REQ-006
- **Derived from**: SYS-CAP-001, SYS-CAP-002, SYS-CAP-006

## FEAT-002: Search and Matching Feature
Groups capability requirements related to searching for and matching candidates, including qualification search, search refinement/alerting, and job categorization.
- **Groups**: CAP-REQ-003, CAP-REQ-004, CAP-REQ-005
- **Derived from**: SYS-CAP-003, SYS-CAP-004, SYS-CAP-005

## FEAT-003: Engagement and Feedback Feature
Groups capability requirements related to profile engagement, notifications, and privacy protection.
- **Groups**: CAP-REQ-007, CAP-REQ-008, CAP-REQ-009
- **Derived from**: SYS-CAP-007, SYS-CAP-008, SYS-CAP-009
